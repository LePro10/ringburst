    How does Ringburst feel?

    Privacy

    Ringburst sends anonymous gameplay stats (score, run length, device type, load time) so I can balance the game. No cookies, no account, no ID that survives a page reload, and I don't store IP addresses. Data is kept on a Supabase server in the EU. Your best score and settings stay on your device. Feedback and leaderboard names are only stored if you send them yourself.
